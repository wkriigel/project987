# Archive

Purpose: preserve historical specifications, explorations, and assets that are not part of the active design.

Structure
- specs/early-exploration: initial requirements, vendor artifacts, scratch notes
- assets/: images and one-off files preserved for context

Conventions
- Read-only: do not edit archived docs; add a new note in `docs/` if you must update thinking.
- Keep filenames; add a `-notes.md` alongside if you need context.
